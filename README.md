## 普通线路和大陆优化线路，差在哪

差在回程路由。优化线路回国走电信 CN2 GIA、联通 CUII（AS9929/AS10099）、移动 CMIN2 这类专用或高端骨干；普通线路走 Telia、Cogentco 等国际骨干绕回来，延迟高，晚高峰还容易被挤爆。

拿具体数据说话：针对 RackNerd 阿姆斯特丹节点（部署在 Equinix AM5 数据中心）的测评显示，该节点走 Colocrossing 基础线路，电信全程经 Telia 骨干、移动经英国节点中转 Cogentco，亚洲方向延迟平均 237ms，日间丢包率低于 1.2%。这个成绩配合 CDN 做外贸独立站是够用的，但如果拿来当日常远程开发或者对延迟敏感的应用，体验会明显吃力。

判断方法很简单：访客和用户主要在海外，普通线路；自己或国内客户要频繁访问，直接上优化线路，这笔钱省不得。
